# AGV 地面站

`index.html` 提供模拟演示、真实串口遥测、地图预演和命令发送；`bridge.py` 将本机串口或已有 TCP 透传服务桥接为 WebSocket。

## 启动

在工程根目录执行：

```powershell
python -m http.server 8080 --directory tools/dashboard
```

浏览器打开 `http://localhost:8080`。默认静止显示右上出发区 1 的中心 `(2250,2250)`，等待连接；不会自动模拟运动或生成演示路径。地图用蓝框标出右上出发区 1、右下出发区 2，均为 300×300 mm。连接真机后以收到的遥测位置为准，不会命令车辆返回出发区。手动选择模拟模式时，模拟车同样从出发区 1 静止开始。地图点击只做本地规划，不会把点击位置下发给车。

接真机时，确认调试器透传串口接到了 USART6 的 TX/RX 并共地，单独接 SWD 不会产生串口数据。串口参数 **115200、8N1**。

```powershell
python tools/dashboard/bridge.py --list
python tools/dashboard/bridge.py --serial COM3 --baud 115200
```

COM3 仅为示例，按枚举结果和插拔确认实际端口。串口桥接需要 `pyserial`；TCP 桥接不需要第三方库。网页选择 WebSocket，填 `ws://127.0.0.1:8766`。端口被占时桥接改 `--port 8767`，网页地址同步修改。也可在支持 Web Serial 的浏览器中直接选择串口。

只有设备确实提供 TCP 透传服务时才使用 `--tcp 实际IP:端口`；“无线”不等于有 IP。连接和控制接口仅用于调试，比赛时如何使用应以规则为准。

## 命令和回执

| 示例 | 含义 |
|---|---|
| F500 / B500 | 前进/后退，整数毫米 |
| L100 / R100 | 左移/右移，整数毫米 |
| A90 / A0.125 | 绝对 IMU 航向角，范围 ±180°，最多三位小数 |
| T90 / T-0.3 | 相对当前航向转动，范围 ±180°，最多三位小数 |
| S | 停车并取消保持；跑图中还会锁止自动运行 |

命令以换行结尾。运动期间新运动返回 BUSY，S 随时有效；跑图/比赛模式拒绝普通运动命令。不要发送 `F1000L500` 这种无分隔串。模拟器是界面演示，不模拟完整的硬件故障和时序。

回执例：`$L,i,ACK,A,OK`、`$L,w,ACK,F,BUSY`、`$L,w,ACK,?,ERROR`。**OK 只表示接受，不代表运动完成**。异常输入/接收溢出会报告 ERROR；回执队列容量有限，溢出次数在 `$H` 中报告。

## 已实现的遥测

模块为 `User/Comm/chassis_telemetry.c`，由底盘任务调用，使用 HAL_UART_Transmit_IT。静态缓冲区在发送完成前不被重写；串口忙时不等待、不打断控制。正常遥测 20 Hz，回执优先。格式化只使用整数，避免依赖 printf 浮点配置。

```text
$T,<ms>,<x>,<y>,<yaw>,<hdgT>,<hdgE>,<state>,<mode>,<r1t>,<r1m>,<r2t>,<r2m>,<r3t>,<r3m>,<r4t>,<r4m>
$V,<vx>,<vy>,<wz>,<dt_s>,<cycle>
$H,<dynamic_peak_deg>,<over_limit_cycles>,<jitter_us>,<ack_dropped>
$C,<initial_imu_yaw>
$L,<level>,ACK,<command>,<result>
```

- `$T`：场地估计位置 mm、IMU 航向及误差 deg、状态 IDLE=0/READY=1/FAULT=2、模式 VEL=0/MOVE=1/TURN=2、四轮目标/测量 RPM。三位小数是传输分辨率，不是实测精度。
- `$V`：斜坡后速度 mm/s、deg/s、控制周期 s 与周期计数。
- `$H`：本次定距运动的最大绝对航向误差、超过 0.2° 的周期数；新运动重置。20 Hz 的 UI 不会覆盖 5 ms 采样累计的峰值，但控制采样和 IMU 采样之间仍可能漏掉物理瞬态。
- `$C`：场地 +X 对应的初始 IMU 航向。首次 READY 时采集原点，假定车位于所选出发区且朝 +X。地图画车时减去此角度，航向表盘保持 IMU 参考。
- `$L`：命令接受结果。未实现运动完成事件。

`$P` 路径和 `$O` 障碍帧仅保留网页解析能力，当前固件没有发送它们。带 `$T` 前缀的文本不能直接宣称兼容仅接收纯数字的绘图协议。

整包最多 511 字节，20 Hz 的理论上界约 10.2 KB/s；实际帧长取决于数值，回执会占用发送机会。115200 8N1 理论载荷约 11.52 KB/s，需在实机核对吞吐、丢帧和控制抖动。若链路跟不上，降低遥测频率，而不要阻塞 5 ms 控制循环。

## 地图和航向要求

车身 **270×270 mm**，额外余量 **10 mm**，外包半尺寸 145 mm。网页四方向 A* 检查完整车体扫掠区域，禁止端点缩小包络；不可停放的起终点直接拒绝。网页全图规划和 MCU 通道受限规划用途不同，不保证路径逐点相同。

航向面板显示三位小数、动态峰值和超限周期数；静态误差超过 0.1°、MOVE 误差超过 0.2° 会变色。静态精度验收需独立角度基准，不能仅凭页面颜色判断。

## 排查

| 现象 | 检查 |
|---|---|
| 连接后无遥测 | 确认已烧录包含遥测的固件、串口接线/波特率；首次 READY 前不发送位置遥测 |
| 发命令不运动 | 查看 ACK：BUSY 代表未就绪、已有运动或模式拒绝；ERROR 代表格式或参数错误 |
| 故障后不恢复 | 新鲜 IMU/四轮反馈恢复后发 S，仍有堵转/保护时不能恢复 |
| 地图位置偏移 | 启动摆放是否满足出发区/+X 假设，编码器方向与尺度是否正确 |
| 精度达不到 | 记录 `$T/$H`，核对 IMU 延迟/漂移、轮速量化、PI、机械死区与打滑 |
| 规划失败 | 起终点或连接段容不下车身和余量；不要靠减小车身包络解决 |

文本命令尚无 CRC、序号、重传去重，原始运动指令也不自动调用场地碰撞检查。完整限制见 [交付清单](../../docs/交付说明与问题清单.md)。
